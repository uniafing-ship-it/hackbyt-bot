Политика конфиденциальности

Hackbyt Bot обрабатывает только данные, необходимые для работы Telegram-бота и публикации сообщений в канале @hackbyt.

Какие данные обрабатываются

Telegram user ID, текст сообщений, отправленных боту, и технические данные, необходимые для обработки запросов.

Использование данных

Данные используются исключительно для выполнения команд пользователя, подготовки и публикации материалов в Telegram-канале.

Хранение

Сервис не предназначен для постоянного хранения пользовательских сообщений. Секретные ключи и токены не публикуются и хранятся в защищённых переменных окружения.

Контакты

По вопросам работы сервиса обратитесь к владельцу Telegram-канала @hackbyt.
