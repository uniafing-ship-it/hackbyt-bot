# Hackbyt — Final Image Style

Create modern editorial cover images for the Telegram channel «Бытовые лайфхаки, которые работают».

The approved visual direction is the dark, high-contrast Hackbyt poster style: realistic photography + bold white typography + neon-lime accents.

## Core rules
- dark / near-black photographic or graphic area;
- white bold modern sans-serif typography;
- neon lime `#C8FF00` for emphasis;
- realistic, high-quality photography;
- one dominant subject / scene;
- strong contrast and clean composition;
- designed to remain readable on a smartphone.

## Layout
Prefer one large photographic scene with a bold headline and a small category badge (`HOME`, `KITCHEN`, `LIFE`, `TECH`, `MONEY`, `DO IT`). A restrained Hackbyt brand mark may appear near an edge.

The image should show the idea of the lifehack at a glance, not explain the whole procedure.

## Text
Allowed: short headline, optional short subheadline, category, small brand mark.

Do not put the full Telegram post on the image. Detailed steps and explanations belong in the caption.

## Strictly avoid
- Pinterest-style infographic layouts;
- three-column step-by-step panels;
- numbered `1 / 2 / 3` instruction cards unless the user explicitly asks for an infographic;
- «КАК РАБОТАЕТ?» blocks;
- long paragraphs;
- many arrows;
- multiple small photos;
- random icons, light bulbs, stars, hammers or clipart;
- beige/olive generic lifestyle styling;
- visual clutter;
- tiny text.

## Collections
For «5 способов», «7 идей» and similar posts, use a poster composition with a large number + short title + one dominant visual concept. Do not turn the image into a multi-panel instruction sheet unless explicitly requested.

## Consistency
Every image must look like it belongs to the same modern media brand as the approved Hackbyt refrigerator and jar examples, while adapting the main photographic subject to the actual post.

If another generic image rule conflicts with these rules, follow this Hackbyt style unless the user explicitly requests another visual style.
